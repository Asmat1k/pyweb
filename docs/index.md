# WebTransport и WebSocket

**Сравнительный анализ технологий двунаправленной передачи данных в веб-приложениях.**

Цель исследования — сравнить время подключения, задержку сообщений,
накладные расходы и поведение при потерях пакетов.

!!! info "Статус исследования"
    Представлены теоретическое сравнение и план экспериментов.
    Измерения не проводились; числовые результаты пока отсутствуют.

## Сравниваемые технологии

| Режим | Транспорт | Доставка |
|---|---|---|
| WebSocket | TLS/TCP | Надёжная, упорядоченная |
| WebTransport streams | HTTP/3 поверх QUIC | Надёжная, порядок внутри потока |
| WebTransport datagrams | HTTP/3 поверх QUIC | Без гарантии доставки и порядка |

Подробнее: [WebSocket](websocket.md) и [WebTransport](webtransport.md).

## Сценарии экспериментов

| Сценарий | Что сравниваем |
|---|---|
| Подключение | Время до готовности: медиана и p95 |
| Обмен сообщениями | RTT для 64, 256 и 1024 байт: медиана, p95, p99 |
| Накладные расходы | Объём сетевого трафика относительно полезных данных |
| Потери пакетов | Доставку до дедлайна и изменение задержки |

Условия описаны в [методике](methodology.md) и [сценариях](scenarios.md).
