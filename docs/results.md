# Результаты

Все результаты последнего запуска показаны на [главной странице](index.md#demo):
медиана и p95 подключения, медиана/p95/p99 RTT, накладные расходы и доля
доставки до дедлайна. Доступна выгрузка полного результата в JSON.

Команда `npm run benchmark` обновляет `docs/assets/demo-results.json`.
Кнопка на главной запускает те же функции в браузере.
[Инструкции запуска и тестирования](running.md).

Реальные сетевые измерения пока не проводились. План описан
в [методике](methodology.md) и [сценариях](scenarios.md).

## Предварительный вывод

| Требование | Кандидат |
|---|---|
| Упорядоченный обмен значимыми сообщениями | WebSocket |
| Несколько независимых надёжных передач | WebTransport streams |
| Частые обновления, устаревшие данные можно пропустить | WebTransport datagrams |

Это выводы из модели доставки, а не рейтинг производительности.
Окончательный выбор требует измерений по общей [методике](methodology.md)
с учётом [ограничений](limitations.md).
