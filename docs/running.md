# Запуск и тесты

## Подготовка

Нужны Node.js 20+ и Python (в CI используется 3.14.8).
Из корня репозитория:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

Если `.venv` уже настроен, достаточно его активировать.
JavaScript использует только встроенные возможности Node.js и браузера.

## Запуск через терминал

```bash
npm run benchmark
npm start
```

Первая команда запускает заглушки и сохраняет все результаты в
`docs/assets/demo-results.json`, перезаписывая предыдущий запуск.
Вторая запускает MkDocs. Откройте [главную](http://127.0.0.1:8000/pyweb/).
Для новой серии повторите `npm run benchmark` и обновите страницу.

## Запуск в браузере

Кнопка «Запустить демо» выполняет те же функции и сразу обновляет таблицы.
Кнопка «Скачать JSON» выгружает текущую серию. Результат браузерного запуска
не сохраняется на сервере: после перезагрузки снова читается JSON из репозитория.
Демо работает и на статическом хостинге, без WebSocket/HTTP/3-сервера.

Все значения случайные. Три режима используют одинаковые диапазоны;
сценарии не имитируют физическое поведение сети. Поддержка WebTransport
в браузере для запуска этих заглушек не требуется.

## Проверки

```bash
npm test
python -m mkdocs build --strict
```

Тесты проверяют все 27 комбинаций сценариев, порядок процентилей,
границы процентов, изменение значений при изменении случайного источника
и формат сохранённого JSON. Это тесты демо, не сетевых протоколов.

Строгая сборка проверяет документацию и локальные ссылки.
Для публикации обновлённых данных сначала выполните `npm run benchmark`,
затем соберите сайт. Сборка включает JS и JSON в `site/`.
