# WebSocket

WebSocket предоставляет постоянный двунаправленный канал текстовых или бинарных
сообщений между браузером и сервером. В этом исследовании рассматривается
защищённое соединение поверх TLS/TCP.

```text
Сообщения → WebSocket → TLS → TCP → IP
```

| Свойство | Значение для сравнения |
|---|---|
| Готовность | Событие `open` в браузере |
| Доставка | Надёжная и упорядоченная в пределах соединения |
| Потери | Восстановление TCP может задерживать следующие сообщения |
| Расходы | Кадры, маскирование клиента, TLS/TCP/IP и повторные передачи |

Кандидат для чатов, уведомлений и команд, где важны порядок и полнота данных.
Подтверждения операций и восстановление состояния после разрыва требуют
прикладной логики.

Источники: [RFC 6455](https://www.rfc-editor.org/rfc/rfc6455.html),
[RFC 9293](https://www.rfc-editor.org/rfc/rfc9293.html).
Сравнение выполняется по общей [методике](methodology.md).
