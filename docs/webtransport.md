# WebTransport

Рассматривается WebTransport поверх HTTP/3 и QUIC: одна сессия предоставляет
надёжные потоки байтов и ненадёжные дейтаграммы.

```text
Streams / datagrams → WebTransport → HTTP/3 → QUIC → UDP → IP
```

| Свойство | Streams | Datagrams |
|---|---|---|
| Доставка | Надёжная, порядок внутри потока | Без гарантии доставки и порядка |
| Границы сообщений | Задаёт приложение | Сохраняются |
| Потери | Восстановление в затронутом потоке | Возможны пропуски |
| Применение | Независимые надёжные передачи | Обновления с ограниченным сроком актуальности |

Готовность сессии определяется выполнением `transport.ready`.
Для потоков нужен прикладной формат сообщений; для дейтаграмм — обработка
пропусков и проверка допустимого размера. Оба режима используют общий
контроль перегрузки соединения: независимость потоков не устраняет все задержки.

Источники: [WebTransport API](https://www.w3.org/TR/webtransport/),
[RFC 9000](https://www.rfc-editor.org/rfc/rfc9000.html),
[RFC 9221](https://www.rfc-editor.org/rfc/rfc9221.html).
Версии браузера и серверной реализации необходимо фиксировать при эксперименте.
