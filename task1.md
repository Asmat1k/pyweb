Задание 1. Генераторы статических сайтов для публикации результатов исследований
Цель работы
Исследовать генераторы статических сайтов (SSG) на Python как инструмент публикации результатов экспериментов и сопровождающих их исследовательских материалов; освоить автоматизацию сборки и развёртывания сайта средствами CI/CD, в том числе на отечественных платформах и хостингах.

Постановка задачи
На основе материалов представленных в данной теме, создать и развернуть на GitHub Pages или аналоге (см. задание P1) собственный статический сайт, используя один из генераторов статических сайтов на Python. Автоматизировать процесс деплоя и реализовать развёртывание на отечественный статический хостинг (подсказка: посмотрите экшен «Static HTML»).

Ответы на вопросы исследовательских заданий и результаты практических заданий отразите в отчёте.

Ход работы
Установить Python актуальной версии
Установить virtualenv
Создать каталог проекта, развернуть в нём виртуальное окружение, активировать его.
Зафиксировать зависимости: requirements.txt с точными версиями пакетов либо pyproject.toml с lock-файлом (uv, poetry). Добавить .gitignore (виртуальное окружение, каталоги сборки site/, _build/, кэш).
Установить MkDocs (или иной выбранный генератор) и создать каркас сайта.
Проверить локальную сборку: mkdocs serve для предпросмотра, затем mkdocs build --strict. Режим --strictпревращает битые ссылки и предупреждения в ошибку сборки — именно это поведение требуется в CI.
Инициализировать репозиторий и отправить изменения на GitHub.
Настроить GitHub Actions
